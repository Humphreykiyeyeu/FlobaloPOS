## How to install


**Windows**
1. Open the file you downloaded.
2. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**. This message is expected for now.
3. Click **Yes** and follow the steps.
4. Frobalo POS opens in your browser. Enter your shop's details.

**Linux**

Open a terminal in the file's folder, then run:
```
sh frobalo-pos-linux-x64.run
```
For a computer used as the shop server, use `sudo sh frobalo-pos-linux-x64.run`.

## Updates

Installed shops get new versions from the **Updates** page in Frobalo POS.
